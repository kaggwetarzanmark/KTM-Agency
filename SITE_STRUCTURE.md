# KTM Agency — Site Structure & Design Reference
> Hand this to your designer. Every page, every section, every SEO note.

---

## TECH STACK
- **Framework:** Astro (static, zero JS by default — best for SEO + speed)
- **Styling:** Tailwind CSS (design tokens go in `tailwind.config.mjs`)
- **Hosting:** Cloudflare Pages (free, global CDN, fast in Africa)
- **Forms:** Netlify Forms or Formspree (no backend needed)
- **Blog/Portfolio:** Markdown files in `src/content/`
- **Sitemap:** Auto-generated by `@astrojs/sitemap` on build

## SEO RULES (enforce on every page)

| Element | Rule |
|---------|------|
| Title tag | Primary keyword + location + "KTM" · max 60 chars |
| Meta description | Keyword + benefit + CTA · max 160 chars |
| H1 | One per page, contains primary keyword |
| H2s | Secondary keywords + related terms |
| Image alt text | Descriptive, includes keyword where natural |
| URL slug | Keyword-based, hyphenated (already set in filenames) |
| Internal links | Every service page links to related services in footer + body |
| FAQ component | Used on all service pages → triggers FAQPage rich snippets |
| Schema | Organisation schema on all pages (in BaseLayout), Article schema on blog posts, FAQPage schema on service pages |

## QUICK START (after design handoff)

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

Deploy to Cloudflare Pages:
1. Push repo to GitHub
2. Connect repo in Cloudflare Pages dashboard
3. Build command: `npm run build`
4. Output directory: `dist`
5. Done — free hosting, global CDN
